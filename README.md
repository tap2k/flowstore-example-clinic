# flowstore-example-clinic

A minimal, **data-only** flowstore example: a clinic appointment-reminder agent
("Asha") as an imported system prompt plus four scripted test cases — including
the same scenario rendered in English and Hindi (joined by `scenario_id`).

This is the canonical client-repo shape: artifacts only, no vendored scripts.
Load it in the compare tool (compare.flowstore.org) or run it with the
flowstore harness. Apache-2.0.
